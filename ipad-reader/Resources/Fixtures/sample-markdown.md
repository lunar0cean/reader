# Markdown 阅读

普通段落里有 **加粗文字**、*斜体* 和 `行内代码`，也可以保留 [链接文字](https://example.com/article)。📚

## 学习清单

- 导入书籍，在书页上批注
- 手指翻页，双指放大
  - 原文与笔迹一起缩放

> 引用仍然保留原文位置，重新排版后可以跳回这一段。

## 代码块

```swift
let page = "页间"
print(page)
```

| 类型 | 用途 |
| --- | --- |
| PDF | 固定版式 |
| Markdown | 排版阅读 |

第三节之后仍然可以继续批注，并把原始 Markdown 与笔迹一起放入可编辑备份。
