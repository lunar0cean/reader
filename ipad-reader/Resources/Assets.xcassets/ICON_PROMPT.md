# 阅读器图标

工具：内置 image_gen.imagegen。原始方形图生成后只做尺寸导出，未修改图像内容。
成品：AppIcon.appiconset/book-1024.png；深青色底、展开的白色书页和书签，不含文字。

最终提示词：

Use case: logo-brand. Create a single polished native iPad app icon for a personal app named 阅读器. Primary subject: one open book, clear ivory-white pages with a subtle central fold and a small teal bookmark, viewed almost front-on with restrained dimensional shading. Background: an opaque deep teal-blue square field, harmonizing with a crisp teal reading toolbar. Strong simple silhouette, generous balanced negative space, recognizable at small icon sizes. Refined practical reading-tool aesthetic. Full square artwork, background reaches all edges, no pre-rounded corners, no outer border, no text, no letters, no extra objects, no device mockup. 1:1 composition.
