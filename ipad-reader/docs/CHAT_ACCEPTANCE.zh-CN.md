## 恢复与出处

- [ ] 重启 App：恢复授权、待发送问题与已接收回复。
- [ ] 断网发送、换 Wi-Fi / 热点后重试：问题和回复没有重复。
- [ ] App 后台停止查询，前台补取迟到回复。
- [ ] 关闭聊天网页后角色仍能响应；如需页面保持打开，记为未达到默认方案。
- [ ] 服务重启、订阅续期、签名轮换后继续接收。
- [ ] 撤销插件 OAuth 后停止投递；重新授权和订阅后恢复。
- [ ] 两个不同会话 / 角色没有串回复；同一会话禁止改绑角色。
- [ ] TXT / EPUB / 文字 PDF / 网页各发送原文，点击引用回到对应原文。
- [ ] 保存到书籍和指定笔记本，重复保存不产生重复条目。
- [ ] Markdown / 原生备份 / 笔记页 SVG 导出恢复后，出处与可编辑内容仍在。
- [ ] 原书、插图和完整笔迹未经主动共享没有上传。
