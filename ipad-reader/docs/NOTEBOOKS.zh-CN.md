# 独立笔记本 V0.7

原生 App 启动进入书库，笔记本与 EPUB、PDF、TXT、Markdown 和网页文档并列。点击笔记本封面直接打开；「新建笔记本」无需先打开任何阅读书。顶部「返回书库」退出。书页批注仍与原文关联，独立笔记本有自己的分区、页面、文字、手写与图片。

每本笔记本记住上次打开的分区和页面。从书库导入 `.yejiannotebook` / 笔记本 JSON 会追加为独立项目；从书库导入页间 SVG 会创建含此页的新笔记本。既有 JSON / SVG 继续支持。

## 布局与画布

- 白色界面、紫色选中项，顶部「开始 / 插入 / 绘图 / 视图」切换对应工具。
- 左侧按「笔记本 → 分区 → 页面」组织。收起导航可依次留下页面列表、隐藏全部目录；「视图 → 导航」重新展开。
- 导航覆盖画布，朝左边缘拖动会跟手移动，快速一甩收回并保持当前笔记页；收起后左上小侧栏图标可重新展开。展开、收起和书写不会改变画布倍率。
- 选择笔或橡皮自动隐藏大工具栏与导航，工具移到固定顶部窄栏；顶部小笔图标退出绘画，右侧展开图标恢复完整工具栏。
- 每个页面都是一个自由画布，**左上角固定为坐标 (0, 0)，向右、向下自动延伸**。横竖屏改变可见范围，不把笔记页重新排版成双页，也不移动原有笔迹。
- 默认以 100% 书写大小打开，双指可缩放；「视图 → 适合宽度」用于按当前可见区域缩小或放大。
- 默认手指移动画布、双指缩放、Apple Pencil 写画；打开「手指绘画」后可用手指写画，原生版双指移动。桌面浏览器可直接用鼠标画图。
- 钢笔、铅笔、荧光笔、整笔橡皮、撤销、重做可用。选择工具可整理原生笔迹；文字和图片可选择、移动、右下角拖动缩放，文字双击编辑。
- 点工具栏的颜色圆点展开 RGB 三条横向滑杆和笔宽滑杆。颜色各通道 0–255；笔宽 0.5–64 pt，步进 0.1，参数保存在本机。
- 「开始」可插入、编辑文字、改变字号和加粗，删除选中的文字或图片。「插入」可添加本地图片和导入文件。「视图」可调整纸色、横线 / 方格 / 空白和适合宽度。

“无限”采用逐段扩展逻辑尺寸，不预先创建巨大的背景位图。原生背景由 `CATiledLayer` 按可见区域绘制，笔迹由 PencilKit 管理。文件校验设有尺寸和笔迹数量上限；大量复杂笔迹的性能仍需真机验证。

## 原生压感与矢量导出

原生画布使用 `PKCanvasView`，由系统处理压感、笔倾角、书写输入和防误触。V0.7 在笔尖落下时暂停外层的缩放和拖动，抬笔后恢复手指导航；避免掌托触碰导致突然放大。画布与对象只在实际内容变化时更新，落笔后不逐笔重复采样整页旧笔迹。

书写期间以完整 `PKDrawing` 二进制和笔迹数量保存，文件编码合并后放入串行后台队列。显式退出／进入系统后台会完成保存。SVG、完整 JSON 或单本导出时再生成压力、宽高、时间、透明度、方位角、倾角和变换矩阵的可移植点列；旧备份继续读取。

SVG 的可见手写部分是随笔宽变化的填充路径，文字是 `<text>`，插图为内嵌位图。**手写不会被导出成一张 PNG。** 分享用的矢量轮廓与 PencilKit 的铅笔纹理、交叠混色和局部擦除遮罩可能有视觉差异；SVG 内保存的原生数据用于恢复原生编辑效果。

浏览器使用 Pointer Events 采样压力并生成同类矢量轮廓。鼠标和无压感笔只能得到固定笔宽，不能用软件生成真实硬件压感。浏览器编辑原生导入的笔迹时，会改用可移植点列并清除旧 `inkData`，避免原生重新打开时被过期数据覆盖。

你描述的 Lightning 插头，如果是 Apple Pencil，就是第一代，支持压感。A16 iPad 与第一代 Pencil 的配对和充电需要 USB-C 转 Apple Pencil 转接器。设备上真实压感、延迟和掌托仍未实测。参考 [Apple Pencil 兼容性](https://support.apple.com/zh-cn/108937)。

## 导出、恢复与本地保存

| 文件 | 内容 | 使用方式 |
| --- | --- | --- |
| 单本 `.yejiannotebook` | 当前这一本的分区、全部页面、对象、压力点列及原生笔迹 | 从书库导入为独立笔记本；可编辑，不包含其他笔记本 |
| 当前笔记页 SVG | 纸张、文字、插图、矢量笔迹，以及页间可编辑元数据 | 分享或重新导入为新页面 |
| 完整笔记本 JSON | 所有笔记本、分区、页面、对象、压力点列及原生笔迹数据 | 完整迁移或备份；导入追加为新笔记本 |

浏览器与原生笔记本共用 `yejian-notebook-v1` 完整备份，SVG 内的元数据格式为 `yejian-notebook-page-v1`。原生在 Application Support 的 `notebooks.json` 保存，浏览器在独立 IndexedDB `yejian-notebooks` 中保存。**本机保存不代表设备间自动同步。**

SVG 中的 `<metadata id="yejian-notebook">` 保存 Base64 编码的 UTF-8 JSON。导入只读取并校验这段数据，不执行 SVG 的脚本或外部引用。支持恢复的是页间导出的 SVG；普通 SVG 没有这些元数据，不能直接恢复为可编辑的笔记页。这也不是 OneNote 文件格式兼容功能。

书库入口统一，阅读器 JSON 保留书籍、原文定位和批注；笔记本 JSON 保留全部笔记本，单本文件保留选中的一本。完整设备迁移需保留两类备份。笔记本目前支持文字、手写、图片，未实现 OneNote 账户同步、录音、表格、OCR 或手写识别。浏览器预览仍使用旧的「更多 → 笔记本模式」入口，本轮改动面向原生 App。

## 验证

`Tests/NotebookTests.swift` 检查压力与笔宽保留、SVG 可编辑恢复、浏览器导出的 SVG 在原生重建、内嵌图片、层级备份、右下扩展保持缩放和可见原点、单本导出及上次页面恢复。`UITests/NotebookUITests.swift` 检查三层导航、绘画、撤销重做、全屏、放大后继续写字保持倍率和对象位置、重新启动后的恢复及横竖屏截图。`UITests/LibraryUITests.swift` 检查独立封面、新建笔记本、返回书库和短距离快速滑动关闭侧栏。

`scripts/check_notebook.cjs` 使用隔离浏览器检查真实鼠标连续笔画、模拟压力采样的序列化、对象移动缩放、图片、右下扩展、SVG / JSON 恢复和书库数据隔离。模拟压力事件和模拟器检查不等于真机 Apple Pencil 测试。

`scripts/check_notebook_native.cjs` 读取原生测试导出的 SVG，检查浏览器恢复原始压力、变换及原生笔迹数据，并在浏览器编辑后正确清除旧原生缓存。

ChatGPT 连接入口及笔记回存接口已有验证实现，真实事件订阅尚未成功，排查暂时暂停。笔记本的页面 ID、对象 ID 和坐标可以接收回答与出处；当前不表示能够自动调用 GPT。
