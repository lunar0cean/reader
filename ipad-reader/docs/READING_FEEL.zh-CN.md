# V0.8 阅读与书写手势

书页顶部扬声器直接开始朗读，再点停止；选中文字后的「朗读」也在当前书页播放。角色、模型和参数位于「朗读设置」。播放使用分段缓冲，完成、停止或进入后台清理生成音频，不保留整段 WAV；角色包、录音和模型保留。

图片双击打开，图片页双击关闭，双指缩放和顶部复制／分享继续可用。纯图片 PDF 长按不生成文字选区，连续长按不会误触图片双击。具有真实文字层的 PDF 才提供文字复制；正文单击隐藏栏仍立即响应。

笔记本从书库选择，导航不再显示第三列笔记本列表。顶部导航按钮依次为「只开页栏 → 分区＋页栏 → 全部收起」。侧栏内容和画布向左快滑可收起导航，收起过程中不切换页面。普通画布移动、双指缩放和 Pencil 书写保留；开启手指绘画时一指绘制优先。顶栏与窄选笔栏统一使用阅读器青色。

最近三个页面缓存各自的 PencilKit 画布、可编辑笔迹、撤销记录、缩放和滚动位置。页面切换解除旧画布回调，不再重新解码未变化的笔迹；保存仍在串行后台队列合并。退出笔记本释放画布与缓存，另一本在主界面直接打开，避免模态页面重复切换造成退出。

书库长按「更换封面」可从照片或文件选择，也可恢复默认。PDF／PPTX 默认第一页；EPUB 优先使用书内声明封面，包括引用位图的 XHTML／SVG 封面页；没有可用图片时回退生成封面。封面随原生可编辑备份保留。

## V0.7 及此前实现记录

V0.7 新增文字长按选择、端点拖动和复制／朗读；插图单点打开独立的可缩放、复制、分享界面。书架完全移除书籍专用栏，笔记本退出也回到独立书库。

笔记本抬笔后只保存可编辑原生笔迹，不重新遍历所有旧笔迹；保存文件在串行后台队列合并处理。背景与对象不因笔迹数量更新而重复配置。笔尖落下时临时停用外层 pinch／pan，抬笔后恢复，处理掌托引起的误放大。SVG 和 JSON 导出仍生成完整可移植矢量点列。

同一次抬笔复用一份序列化结果，避免再次编码整页原生笔迹，也避免界面误认为外部笔迹变更而重新加载。已经生成矢量点列的页面在导出时保留原笔画 ID。

页内长按和选择端点优先于翻页手势，Pencil 与手指选择分开；开启批注后默认手指仍可复制、翻页和双指缩放。离线朗读模型只在用户点击朗读后加载，避免启动阅读和书写就占用大量内存。

这轮优先改原生 iPad 手感，ChatGPT 事件连接排查暂时暂停。现有书籍、跨页笔迹和备份格式继续使用。

本版针对实机反馈继续修改：PDF 翻页使用三个相同几何的缓存页面，移入的页面直接成为正式页面。未变化的纸面不会因阅读进度更新重新绘制；阅读进度合并后在串行后台队列编码保存，显式保存和后台退出按同一队列顺序写入。

翻页按释放速度和预计位移决定完成或弹回，完成动画按剩余距离和速度调整。目录、助手和笔记本导航使用 UIKit 拖动，左栏向左、右栏向右，短促快速滑动也可收起。收栏手势取消行点击，保持原来的页面；笔记本导航覆盖画布，展开或收起不重新适合宽度。

笔记本扩展尺寸时只改逻辑 bounds 与中心，保留外层缩放和滚动位置；固定 PencilKit 内层为 1 倍，扩展在落笔结束后执行。写字、保存、扩展尺寸不触发适合宽度。打开另一个页面从 100% 开始，主动点「适合宽度」也可设置倍率。

启动 App 进入统一书库，笔记本作为独立项目与 TXT / EPUB / PDF / Markdown / 网页并列。可从书库新建、打开或导入笔记本，不依赖某本阅读书。顶部「返回书库」退出笔记本；`.yejiannotebook` 文件只包含这一本及其全部分区、页面和可编辑内容。

V0.6 新增测试：PDF 翻页前后纸页几何一致、Markdown 样式／字符／出处恢复、缩放后写字不改变倍率与位置、画布扩展保持倍率与左上原点、书库独立笔记本和快速滑动收栏、笔记本单独导出及上次页面恢复、延迟进度不能覆盖新保存。

- 整页状态下，手指左右拖动时纸面跟随手指，松手后完成翻页或弹回；底部箭头使用同一滑动动画。放大后，一指拖动查看页面，双指缩回整页后再翻页。
- 双指缩放同时变换原文与笔迹，范围为整页的 1–4 倍，不改变字体、分页、出处或笔迹坐标；旋转屏幕重新适配单页／双页。
- 点顶部笔图标进入批注，书名栏与底部进度栏收起，笔、橡皮、撤销和颜色只保留在顶部窄栏。轻点书页或顶部收起图标隐藏选笔工具，顶部小笔图标仍可退出批注。
- 默认只接受 Pencil 写画，手指可以翻页、缩放。设置中的「允许手指绘制」为兼容选项，启用后一指用于画画，双指仍能缩放；恢复默认即可用一指翻页。
- 阅读与笔记本共用 RGB 三条滑杆（各 0–255）和笔宽滑杆（0.5–64 pt，步进 0.1）；选色和笔宽在设备本地保存。
- 独立笔记本选择笔／橡皮时自动收起大工具栏与导航，顶部仍保留选笔、橡皮、撤销和退出按钮。手指拖动画布，双指缩放，画布仍从左上向右下扩展。
- 目录与助手侧栏滑入／滑出，点击外侧或向屏幕边缘拖动可关闭。

验收覆盖：跨两页的一笔、撤销／重做、默认手指翻页、整页缩放后笔迹数量与页码不变、竖屏同一笔的两半、RGB 参数、笔记本对象移动及保存后重开。模拟器使用显式允许手指绘画来产生测试笔迹；真实 Pencil 压感与持续手势需要安装后在本人 iPad 复核。
