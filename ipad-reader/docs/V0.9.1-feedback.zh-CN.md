# 0.9 使用反馈与修复

本轮处理删除、分类、导入进度和排版性能；整体 UI 风格替换、美化已记录，暂不实施。

- 书架长按书籍或独立笔记本：删除、更换封面、移到分类。
- 分类可以新建、重命名、删除；删除分类不会删除内容。
- 笔记本导航长按页面或分区可以删除；最后一页删除后保留新的空白页。
- 删除后提交新的存储索引，再回收对应旧记录；空书库可备份、恢复。
- XML 解析完成后释放临时栈，消除保留整棵解析树的自引用。
- PPT 解压资源、关系与 XML 缓存复用；位图缓存限定 32 MB。
- PPT 转换显示页数和阶段，可取消，超时停止；不再在导入时重复提取转换 PDF 全部文字。公式的实际选中和朗读仍使用原页 PDF 文字。
- 重排在后台执行，连续改参数合并；有笔迹的 EPUB/TXT/MD 保持原版式，整页缩放不改变笔迹与内容的对应关系。

后续：用字符范围／段落锚点重建划线与圈画；复杂草图、跨段箭头保留原版式快照，提供可撤销人工迁移。当前不把屏幕坐标强行套到重排后的文字上。

显示问题需用真实文件验证：2026-10-14 截图「Ch6_同步电机 2026」第 28、29 页，公式拆行、下标错位、标题背景缺失。未经原文件渲染比对不宣称完整修复。PDF 与 PPT 固定页仍按原始比例完整显示；竖屏横向课件上下留白是按比例适配结果。
